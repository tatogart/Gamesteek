# Gamesteek 💿

Простая база для учёта продаж дисков с играми: покупатели, склад игр, продажи, расходы и прибыль.
Работает целиком в браузере, без сервера — подходит для GitHub Pages.

## Что умеет

- **Главная** — выручка, чистая прибыль, расходы, средний чек, долги по оплате, стоимость склада,
  график по месяцам, топ игр и покупателей, заканчивающиеся позиции. Фильтр по периоду.
- **Продажи** — игра, покупатель (можно создать прямо из формы), количество, цена, себестоимость,
  способ оплаты, статус (оплачено / ждёт оплаты / отменено). Прибыль считается автоматически.
- **Покупатели** — контакты, сколько раз купил, сколько потратил, прибыль с покупателя, история покупок.
- **Игры** — платформа, состояние (новый / б/у), цена закупки и продажи, остаток. Остаток уменьшается
  при продаже и возвращается при отмене или удалении продажи.
- **Расходы** — доставка, реклама и прочее, вычитаются из прибыли.
- **Данные** — резервная копия в JSON и восстановление, экспорт таблиц в CSV (открывается в Excel), демо-данные.

## Где хранятся данные

По умолчанию — в `localStorage` браузера: у каждого устройства своя база.
После настройки Firebase (ниже) база общая для всех ваших устройств и открывается только после входа
через ваш Google-аккаунт. Регулярно скачивайте резервную копию на вкладке «Данные».

## Общая база через Google (Firebase)

Бесплатно (тариф Spark). Займёт около 5 минут.

1. Откройте https://console.firebase.google.com → **Создать проект** (название любое, например `gamesteek`).
   Google Analytics можно отключить.
2. **Authentication** → **Начать** → вкладка **Sign-in method** → **Google** → **Включить** → укажите свою почту → **Сохранить**.
3. **Authentication** → **Settings** → **Authorized domains** → **Add domain** → `tatogart.github.io`.
4. **Firestore Database** → **Создать базу данных** → регион `eur3 (europe)` → режим **production**.
5. Вкладка **Rules** → вставьте содержимое файла [`firestore.rules`](firestore.rules),
   замените `ВАШ_EMAIL@gmail.com` на свой адрес → **Publish**. Именно это правило закрывает доступ всем, кроме вас.
6. **Настройки проекта** (шестерёнка) → **Ваши приложения** → значок **`</>`** (Web) → название любое →
   **Зарегистрировать**. Скопируйте объект `firebaseConfig`.
7. Вставьте его в файл [`firebase-config.js`](firebase-config.js) вместо `null`
   (`window.FIREBASE_CONFIG = { apiKey: "...", ... };`) и сохраните в `main`.

После этого сайт попросит войти через Google. При первом входе можно загрузить в облако данные,
уже введённые на этом устройстве. Ключи из `firebaseConfig` не секретные — их можно хранить в открытом репозитории,
доступ к данным определяют только правила из шага 5.

## Публикация на GitHub Pages

1. Слейте изменения в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт по адресу
   `https://<пользователь>.github.io/<репозиторий>/`.

Локально достаточно открыть `index.html` в браузере.
